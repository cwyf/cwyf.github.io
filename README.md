# cwyf.github.io

个人游戏制作实践与开源工具网站。

- 网站：https://cwyf.github.io/
- 资料页：https://github.com/cwyf
- 公开 skill：https://github.com/cwyf/godot-moebius-rendering

纯静态页面，入口为 `index.html`，无需安装依赖或构建。通过 GitHub Pages 从 `main` 分支根目录发布。

页面展示作者 Godot 游戏测试副本的实机画面，并提供同机位原始工程与多轮迭代结果对比。截图不随开源 skill 的 MIT 许可证授权；本仓库不包含完整游戏工程或模型资产。

支持游戏截图大图浏览、键盘切换，以及房屋 / 村落前后对比分界线拖动。无 JavaScript 时仍可浏览图片并打开原图。

字标使用 Newsreader，正文使用 Noto Sans SC，均来自 Google Fonts 官方仓库并按 SIL Open Font License 使用。许可证见 `assets/Newsreader-OFL.txt` 与 `assets/NotoSansSC-OFL.txt`。网站托管按页面字形裁剪的 WOFF2 字体，不依赖第三方字体服务。后续新增中文文案时需重新生成字形子集。
